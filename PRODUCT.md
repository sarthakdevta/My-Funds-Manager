# Product scope

Money Manager is intended to be a personal finance workspace first, with a secure multi-user architecture for later distribution.

## Primary flows
1. Sign up / sign in.
2. See current financial position.
3. Record income/expenses.
4. Track accounts and balances.
5. Set monthly budgets.
6. Create savings goals.
7. Create financial tasks and optionally turn completed payment tasks into expenses.
8. Track recurring subscriptions.
9. Review reports.
10. Export a backup.

## Planned next releases
- Account reconciliation.
- Recurring transaction engine.
- Receipt attachments using private object storage and signed URLs.
- Month selector and historical budget views.
- CSV import/export.
- Notifications for due tasks/subscriptions.
- MFA enforcement and device/session management.
- Native macOS packaging.
- Automated integration tests against a test Supabase project.
